# 🌤️ Climify App - A simple and free weather viewer.

**Climify** is a clean and lightweight web application designed to check real-time weather conditions based in your city and worldwide using the OpenWeatherMap API.

---

## 1. Project Overview & Scope
* **Core Purpose:** A simple, responsive web dashboard built to fetch and display real-time global weather data.
* **Tech Stack:** Engineered cleanly using HTML5, CSS3, and modern JavaScript.
* **Key Focus:** Highlights real-world practice with modern coding methods, pulling live information from the web automatically, and filtering data on the spot.

---

## 2. How It Works
*   **Search:** Submitting a city name starts the weather lookup.
*   **Fetch:** The app requests live data from the OpenWeather API in the background.
*   **Black Magic:** The "Clima" class takes that raw data and organizes it into a clean package.
*   **Render:** The UI updates instantly with the new weather info without reloading.

---

## 4. Installation & Usage Guide

### 📋 Prerequisites
*   Your preferred browser (Chrome, Safari, Edge, or Firefox).
*   A free API Key from [OpenWeatherMap](https://openweathermap.org/).

### 🛠️ Step-by-Step Setup
*   **Step 1: Get the Code**
    *   Click the green **"Code"** button at the top right of this repository.
    *   Select **"Download ZIP"** and extract the contents to a folder on your computer.

*   **Step 2: Configure your API Key**
    *   Open the `app.js` file using your favorite text editor or IDE.
    *   Locate line 3 in the file.
    *   Replace `YOUR_API_KEY_HERE` with your actual OpenWeatherMap key and save the changes.

*   **Step 3: Launch the App**
    *   Double-click the `index.html` file to open it in the browser of your choice.
    *   Type any city name, hit **"Search"**, and enjoy the live weather updates!
